# Eye tracking on PSVR2 PC

Correction (2026-09-06): first RigMR docs treated Sony's official PC feature cut as the last word. That was wrong.

| Layer | Eye tracking | Notes |
| --- | --- | --- |
| Sony official PC adapter + app | No | Also no HDR / rumble / adaptive triggers |
| PSVR2Toolkit | Yes, with calibration | Unofficial driver mod. Non-commercial. |
| OpenXR Eye Trackers (mbucchia) | Obsolete | Built into Toolkit; uninstall the old layer |
| PimaxMagic4All | Consumes gaze for OpenVR DFR | NVIDIA |
| Quad-Views-Foveated | Consumes gaze for a few OpenXR titles | Broader GPU support |
