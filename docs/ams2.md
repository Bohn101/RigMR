# Automobilista 2

Shared memory map name: `$pcars2$`

In-game: Options → System → Shared Memory = Project CARS 2.

UDP exists (port 5606) but is slower. RigMR reads shared memory.

Launch AMS2 in SteamVR mode with SteamVR as the OpenXR runtime. Hide the virtual steering wheel in cockpit options if you want the physical rim + mask to own that volume.
